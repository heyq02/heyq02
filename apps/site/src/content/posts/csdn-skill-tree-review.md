# CSDN C / Python 技能树使用体验：暂不推荐

个人觉得目前的技能树，额，说的好听点，还有很多地方有所欠缺。难听点，真的很失败，完全没有发挥出CSDN社区大牛众多的特点，而是照猫画虎，想模仿MOOC那一套，结果丢失了自己原本的韵味。打分C,暂时不推荐大家使用。

## 一、明显缺点

我是按照学习顺序从C技能树第一节开始的，下列几个问题都很突出，在第一次使用就给了我很不好的感觉。

### 1. 内容关联性较差

以C技能树>C语言概述>C语言发展史为例。进入学习，大家可以看见目前的有五条。点进去后也是可以下拉出很长的内容。

![](https://i-blog.csdnimg.cn/blog_migrate/b4e78d08786e6fc6a11ab64a0fa348d3.png)

然而，看似很多的内容却有很多的“水分”。我们进去这个浏览量788的文章，其中与这一章节有关的内容却寥寥无几。更多的却是所谓“耗费一夜总结三本C语言系列”，实在关联性不大！

![](https://i-blog.csdnimg.cn/blog_migrate/29a6f5755379cc80b71ff9b21664532f.png)

### 2. 习题针对性较差

当我在练习C技能树>C语言概述>C语言特点时，我不由得升起一丝疑惑，这练习题和C语言特点有啥关系。题目的标题很有趣，打印C语言的特点，而联系题确实在考""的语法知识，不觉得是“人迷惑行为”么。这给我的感觉不像是在吸引学生，而是在劝退一些“菜鸟”。

![](https://i-blog.csdnimg.cn/blog_migrate/9c1f24aa24f35ac3be20b38d66712ba0.png)

![](https://i-blog.csdnimg.cn/blog_migrate/dadb8f3ed1cc8ae70be49734440cd63d.png)

### 3. 板块混乱

虽然叫做技能树，但是在内容方面，似乎只是浮于表面的树。每一篇文章，都是自顾自的延伸，被包含在这个知识点内只不过是因为稍稍擦边了一点知识点。进去之后只是和一本书的提纲无二样。没有充分体现“树”的内涵。

## 二、改进建议

### 1. 增强内容审查

内容在精不在多，看似很多个博客，进去后才发现与中心知识点只是“擦边”关系，这是教学的忌。可以说这个知识点较为简单，那么内容可以安排较少，但不能随便找一篇“擦边文”就塞进去混篇数。这一点MOOC做得就很好，内容有多有少，但关联性都很强，直指知识点。

![](https://i-blog.csdnimg.cn/blog_migrate/b3c8b3fc69e7410cce913c20c756a10e.png)

### 2. 增加答疑区

CSDN为什么要像MOOC一样设置讨论区呢？我们的优势是“专”，即使编程有分C、、Java……但相比其他任何编程教学软件（即使是MOOC），我们的专业性肯定是最强的。不妨直接让学生将问题“悬赏”出来，付出一定的代价，让CSDN官方交由编程大牛进行解答。才能更好的发挥出CSDN较之其他社区的优势。

粘贴一份MOOC上的讨论区截图

![](https://i-blog.csdnimg.cn/blog_migrate/992a05c78444d7100dd8dc17bd9fc0d0.png)

回复寥寥无几，进去查看他人回复也很困难。MOOC上的教师都基本有本职工作，拍摄MOOC也不过是完成任务，与其没有利益相关性。而CSDN上的创作者可以根据学生提出的问题撰写博客，并由官方将置于答疑区的问题上，并标注（已被解答），既给予创作者写博客的灵感，又能解答学生的疑惑，不失为两全之计。
